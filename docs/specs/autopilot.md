# Автономность: сервис, живущий годами без человека

_Задача: довести ai-dev-daily до состояния «боевая машина» и перевести доставку на
бота `@businessman_news_bot` в публичный канал. Класс: **L**. Предшественники:
`daily-service.md` (исходное ТЗ), `heartbeat.md` (внешний контур наблюдения)._

## Что значит «работает годами без вмешательства»

Сервис уже переживал **падения**: ретраи, деградация Perplexity, алёрт на сбой,
идемпотентность, heartbeat. Не переживал он другое — **медленное тихое гниение**,
где ничего не падает, а качество утекает. Пять таких классов найдены разведкой
и закрыты; каждый выглядел как «всё хорошо».

| Класс | Как выглядел | Что сделано |
|---|---|---|
| Авария на публику | Пост и алёрты имели одного адресата. С переездом в канал «⚠️ Дайджест не отправлен» стало бы публикацией | Адресаты разведены: `TELEGRAM_ALERT_*` с fallback на прежние ключи |
| Сбой стоит суток | Один заход в 04:00; моргнувшая сеть = день без поста | Три захода (04:00/04:30/05:00), шумит только последний |
| Смерть источника | `gather` считал только «выжил ли хоть один». Протухший токен X = пост беднее на 60 материалов, в логе WARNING, который под cron никто не читает | Счётчики **по каждому** источнику; ноль → уведомление владельцу |
| Протухание ключа | Узнавали по поломке | GitHub PAT объявляет срок заголовком — предупреждаем за 14 дней |
| Бесконечный рост | Логи и суточные `digest-*.json` копились вечно | logrotate + прунинг снимков старше 90 дней |

## Ключевые решения

1. **Fallback у обоих алёрт-ключей.** Отсутствие ключа — штатная конфигурация, не
   поломка. Иначе выкат кода до правки env уронил бы именно контур уведомлений —
   тот единственный, который обязан сообщать о поломках.

2. **Отдельный бот для аварий, а не только отдельный чат.** Telegram запрещает боту
   писать пользователю первым, пока тот не нажал Start. Бот канала этого права может
   не иметь, и без развилки работоспособность алёртов зависела бы от ручного
   действия человека — ровно то, от чего уходим. Боевая конфигурация оставляет
   аварии на прежнем боте: с ним владелец уже переписывался.

3. **Промежуточная попытка не пишет `failure` в heartbeat.** Сторож читает `failure`
   как состоявшуюся поломку (`analyzeAiDevDailyFindings`) и алёртит. Отметка при этом
   **не подделывается**: она просто остаётся прежней. Если следующей попытки не
   случится вовсе, сторож увидит протухшую отметку и сообщит честно — то есть
   молчание промежуточной попытки не создаёт слепого пятна.

4. **Успех отмечается всегда, провал — только на последней попытке.** Успех
   окончателен: следующие заходы его не изменят, они просто выйдут по
   идемпотентности.

5. **Cooldown на уведомления — 7 дней на ключ.** Мёртвый источник остаётся мёртвым
   неделями. Ежедневное сообщение об одном и том же приучает не читать алёрты ровно
   к тому дню, когда случится настоящая авария.

6. **Конфигурация запуска ушла из crontab в `/etc/ai-dev-daily/ai-dev-daily.env`.**
   С тремя заходами длинная строка размножилась бы втрое. Файл вне git осознанно:
   имена секретов — карта инфраструктуры (решение из `config.py`).

7. **Уборщик не трогает непонятное.** Имя, не разбирающееся в дату, пропускается: в
   каталоге лежат чужие файлы (ручной `digest-2026-07-19.md`), и удалять
   неопознанное — худший возможный дефолт.

8. **Внешний `timeout` поверх прогона.** Внутренний потолок не спасает от зависания
   в неожиданном месте — в первую очередь в `az` без интерактивной сессии. Висящий
   процесс держит lock, а следующий заход по правилу не отбирает lock у живого
   владельца, то есть один висяк молча съедает утро.

## Границы

- **Внешний dead-man's switch не заводим** (решение владельца 2026-08-14). Мёртвый
  хост целиком по-прежнему не покрыт: сторож живёт на том же mh-central. Issue #4
  остаётся с прежним триггером 2026-11-12.
- **Редакционная рамка не меняется**: тот же отбор для разработчиков, `prompt.md` и
  `arman_style.md` не тронуты. Меняется только транспорт.
- **Качество курации по-прежнему не покрывается автотестом** — «хороший отбор» не
  выражается критерием да/нет. Проверяется глазами.

## Переезд доставки (выполнен 2026-08-14)

Дайджест уходит ботом **`@businessman_news_bot`** (`AiNews`, id `8910627711`) в
приватную супергруппу **«Вайбкодинг от Армана»** (`-1004469714973`).

⚠️ **`businessman--production--TELEGRAM-CHANNEL-ID` для этого не годится**: вопреки
имени, там лежит `201374791` — личный чат владельца, а не канал. Адрес группы
заведён отдельным секретом `ai-dev-daily--prod--TELEGRAM-CHANNEL-ID`.

Токен нового бота читается **из namespace `businessman`**, а не копируется в свой:
копия секрета в двух местах расходится при первой же ротации, и чинят обычно
только одну.

**Аварии остались на ПРЕЖНЕМ боте** `ai-dev-daily` в личку владельца. Не из
осторожности, а по механике Telegram: боту запрещено писать пользователю первым,
пока тот не нажал Start. С новым ботом владелец не переписывался, и авария молча
не доставилась бы ровно в тот момент, когда она нужнее всего.

Проверено обоими исходами, отправкой:

| Что | Куда пришло | Чем подтверждается |
|---|---|---|
| Дайджест | группа `-1004469714973` | `message_id=413` — новая нумерация, то есть другой чат |
| Авария | личка `201374791`, `type: private` | `message_id=1878` — продолжает нумерацию лички, значит прежний бот |
