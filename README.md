# ai-dev-daily-search

Мини-сервис: каждое утро ищет свежие **прикладные** новости про ИИ-разработку по мировым
источникам, курирует по строгим критериям и присылает **дайджест-пост от имени Армана**
(подача через выгоду читателя) в Telegram.

Статус: **пробный боевой прогон сделан 19.07.2026** (пост отправлен в Telegram).
Осталось оформить в сервис с утренним cron.

---

## Что в папке

```
ai-dev-daily-search/
├── README.md                     ← этот файл
├── prompt.md                     ← промт поиска/отбора/формата (обезличенный, мировые источники)
├── sources.md                    ← каталог источников (RSS/аккаунты/движки)
├── arman_style.md                ← стиль-гайд Армана (референс подачи)
├── .env.example                  ← имена переменных окружения (без значений)
├── pipeline/
│   ├── config.py                 ← разрешение секретов: env → Azure Key Vault
│   ├── collect.py                ← сбор кандидатов: X.com + Exa + GitHub
│   └── send_post.py              ← финальный отправитель поста в Telegram (выгода-подача)
├── data/
│   ├── digest-2026-07-19.md      ← финальный текст отправленного поста
│   ├── candidates-2026-07-19.json (регенерируется collect.py — см. ниже)
│   └── pimenov-sitemap.json      (карта сайта-референса, при наличии)
└── research/                     ← скрейпы референсных статей (Firecrawl), при наличии
```

> Файлы `data/candidates-*.json`, `pimenov-sitemap.json` и `research/*` — это выход разовых
> прогонов; их временная копия в `/tmp` подчистилась. Регенерируются запуском `collect.py`
> и Firecrawl. Канонические артефакты (скрипты, промт, источники, текст поста) — на месте.

## Как работает пайплайн

1. **Сбор** (`pipeline/collect.py`) — три живых источника:
   - **X.com** recent search (4 запроса, свежие твиты практиков) — 450 req/15мин
   - **Exa** нейропоиск (4 запроса, статьи/блоги с фильтром по дате)
   - **GitHub** search свежих репо (`created:>`)
   → `data/candidates.json`
2. **Курация** — отбор по критериям `prompt.md`: конкретика + прикладная выгода, анти-фильтр
   режет крипту/рекламу/хайп. Отбирается 3–6 материалов + «на радаре».
   (В пробном прогоне курировал Claude вручную; в проде — 1 вызов Anthropic API.)
3. **Отправка** (`pipeline/send_post.py`) — пост в Telegram-HTML от имени Армана, подача
   через выгоду читателя, через Telegram-бота в чат получателя.

## Запуск вручную

```bash
cp .env.example .env    # подставить имя своего Key Vault и имена секретов
set -a && . ./.env && set +a

python3 pipeline/collect.py     # → data/candidates.json
# (курация)
python3 pipeline/send_post.py   # → пост в Telegram
```

## Секреты и конфигурация

Значений ключей в репозитории нет и быть не может. `pipeline/config.py` разрешает каждый
секрет так: сначала одноимённая переменная окружения (готовое значение — для локального
прогона), иначе — Azure Key Vault, где хранилище задаётся `KEYVAULT_NAME`, а имя секрета —
переменной `<KEY>_SECRET`. Полный список переменных — в `.env.example`.

| Назначение | Логический ключ |
|---|---|
| X.com recent search | `X_BEARER_TOKEN` |
| Exa neural search | `EXA_API_KEY` |
| GitHub search | `GITHUB_TOKEN` |
| Курация (Claude) | `ANTHROPIC_API_KEY` |
| Доставка Telegram | `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` |

## Решения по подаче (зафиксировано в сессии 19.07.2026)

- **Голос Армана** (`arman_style.md`): просто, коротко, от первого лица, без пафоса.
- **Личный канал** — без самопредставления («Это Арман» убрано).
- **Через выгоду** — каждый пункт отвечает «что вам это даёт»: применю в деле / научусь / сэкономлю.
- **Без концовки-вопроса и подписи** — финал на выгодном призыве к действию.

## Открытые развилки (для перевода в боевой сервис)

1. **Время** утренней отправки + таймзона (cron в UTC).
2. **Движок курации:** Claude solo vs Perplexity-поиск + Claude-проверка.
3. **Канал:** Telegram (готов) vs +Email (SendGrid) vs отдельный канал/бот.
4. **Namespace ключей:** переиспользовать существующий или завести свой `ai-dev-daily--*`.
5. Дедуп (`sent_history.json`) — не подключён в пробном прогоне, нужен в проде.

## Ещё не сделано в коде

- `collect.py` — дата прогона зашита константой (`datetime(2026,7,19)`) для
  воспроизводимости пробного прогона; в проде нужен `datetime.now(timezone.utc)`.
- `send_post.py` — текст дайджеста от 19.07 вшит литералами; для сервиса нужен
  генератор поста из результата курации.
- Шага курации как кода нет — в пробном прогоне отбор делался вручную.

## Деплой (план)

Секреты — из Key Vault в рантайме (не в git, не в env-файл с реальными значениями).
